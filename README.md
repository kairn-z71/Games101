## 推荐用 Obsidian 阅读
完整克隆后用 Obsidian 打开整个仓库目录，保留 Lessons/ 与 Pictures/。
笔记使用 Obsidian 内部链接、图片嵌入和 callout，GitHub 网页可能不能正确跳转或显示正文图片。
图片原文件可以在 Pictures/ 中查看。

常用分支统一为 main；原 ai-polished 中已有的课程改动已保留。
