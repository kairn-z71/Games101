# Whitted-Style Ray Tracing

## 介绍

- Whitted-Style Ray Tracing 是现代路径追踪（Path Tracing）的前身。

| 对比   | Whitted | Path Tracing |
| ---- | ------- | ------------ |
| 采样光线 | 反射光/折射光 | 随机采样         |
| 阴影   | 硬阴影     | 软阴影          |
| 全局光照 | ❌ 没有    | ✅ 有          |
| 真实感  | 中等      | 很高           |
| 速度   | 快       | 慢            |

## 核心思想

> [!NOTE]
> - Whitted Ray Tracing 是一个**递归算法**：
>
> $$
> \text{Whitted-Style Ray Tracing}=\text{Shadow Mapping
> }+\text{反射世界} + \text{折射世界}
> $$
> 
> ```cpp
> Color(ray):  
> 	hit = intersect(ray)  //光线第一个打到的物体
> 	if no hit:  
> 		return background  
> 	  
> 	color = local_shading(hit)  
> 	  
> 	if reflective:  
> 		color += reflection * Color(reflected_ray)  
> 	  
> 	if refractive:  
> 		color += refraction * Color(refracted_ray)  
> 	  
> 	return color
> ```
> 

## 算法缺点

|✅ 能做到（支持）|❌ 做不到（不支持）|
|---|---|
|硬阴影（Shadow Ray）|软阴影（Area Light）|
|镜面反射（Reflection）|漫反射间接光（Diffuse GI）|
|折射（Refraction）|颜色反弹（Color Bleeding）|
|直接光照（Direct Lighting）|全局光照（Global Illumination）|
|高光（Specular Highlight）|多次漫反射（Multiple Diffuse Bounce）|

👉 因为它**只追踪“反射光 折射光”**，没有随机采样

#### Möller–Trumbore 算法

##### 用途

1. 光线和三角形求交

##### 算法

- 补充数学知识👇
	1. [[2.Linear Algebra#克拉默法则]] 
	2. [[2.Linear Algebra#性质|2.Linear Algebra#叉乘性质]] 

注意：以下粗体字母都是向量  （可以表示坐标，也可以是向量）

> [!NOTE]
> 矩阵公式
>
> 
> $$
> \begin{aligned}
> &\mathbf{Given:} \quad
> \mathbf{R}(t)=\mathbf{O}+t\mathbf{D},\quad
> \mathbf{P}(u,v)=(1-u-v)\mathbf{V}_0+u\mathbf{V}_1+v\mathbf{V}_2  
> \\ \\
> &\mathbf{Intersection:} \quad \mathbf{O}+t\mathbf{D}=(1-u-v)\mathbf{V}_0+u\mathbf{V}_1+v\mathbf{V}_2
> \\
> &\to  -t\mathbf{D}+u(\mathbf{V}_1-\mathbf{V}_0)+v(\mathbf{V}_2-\mathbf{V}_0)=\mathbf{O}-\mathbf{V}_0 
> \\ \\
> &\mathbf{Let:} \quad \mathbf{E}_1=\mathbf{V}_1-\mathbf{V}_0,\;\mathbf{E}_2=\mathbf{V}_2-\mathbf{V}_0,\;
> \mathbf{T}=\mathbf{O}-\mathbf{V}_0
> \\  \\
> &\begin{pmatrix} -\mathbf{D}&\mathbf{E_{1}}&\mathbf{E_{2}} \end{pmatrix}  
> \begin{pmatrix} t \\
> u \\
> v \end{pmatrix} =\mathbf{T}
> \\  \\ \\
> &\mathbf{Cramer's \ Rule:}  
> \\ \\
> &t=\frac{
> \det\begin{bmatrix}
> \mathbf{T} & \mathbf{E}_1 & \mathbf{E}_2
> \end{bmatrix}
> }{
> \det\begin{bmatrix}
> -\mathbf{D} & \mathbf{E}_1 & \mathbf{E}_2
> \end{bmatrix}
> }
> =\frac{
> \mathbf{T}\cdot(\mathbf{E}_1\times\mathbf{E}_2)
> }{
> (\mathbf{D}\times \mathbf{E_{2}})\cdot\mathbf{E}_1
> }
> \\
> &u=\frac{
> \det\begin{bmatrix}
> -\mathbf{D} & \mathbf{T} & \mathbf{E}_2
> \end{bmatrix}
> }{
> \det\begin{bmatrix}
> -\mathbf{D} & \mathbf{E}_1 & \mathbf{E}_2
> \end{bmatrix}
> }
> =\frac{
> (\mathbf{D}\times\mathbf{E}_2)\cdot\mathbf{T}
> }{
> (\mathbf{D}\times\mathbf{E}_2)\cdot\mathbf{E}_1
> }
> \\ 
> &v=\frac{
> \det\begin{bmatrix}
> -\mathbf{D} & \mathbf{E}_1 & \mathbf{T}
> \end{bmatrix}
> }{
> \det\begin{bmatrix}
> -\mathbf{D} & \mathbf{E}_1 & \mathbf{E}_2
> \end{bmatrix}
> }
> =\frac{
> (\mathbf{D}\times\mathbf{T})\cdot\mathbf{E}_1
> }{
> (\mathbf{D}\times\mathbf{E}_2)\cdot\mathbf{E}_1
> }
> \\ \\ \\
> &\mathbf{Let:}  \quad \mathbf{P}=\mathbf{D}\times\mathbf{E_{2}},\;
> \mathbf{Q}=\mathbf{T}\times\mathbf{E_{1}} \\
>  \\
> &\begin{pmatrix} t \\ u \\ v \end{pmatrix} =\frac{1}{\mathbf{P}\cdot \mathbf{E_{1}}}
> \begin{pmatrix} \mathbf{Q} \cdot \mathbf{E_{2}}  \\
> \mathbf{P}\cdot \mathbf{T} \\
> \mathbf{Q}\cdot \mathbf{D}
> \end{pmatrix} 
> \end{aligned}
> $$
>
> ---
> | 符号  | 英文全称 (或词源)              | 中文含义       |
> | --- | ----------------------- | ---------- |
> | V​  | Vertex                  | 顶点         |
> | E​  | Edge                    | 边          |
> | O   | Origin                  | 射线起点       |
> | D   | Direction               | 射线方向       |
> | T   | Triangle to Origin      | 从顶点指向起点的向量 |
> | P   | Primary cross product   | 第一个叉积结果    |
> | Q   | Secondary cross product | 第二个叉积结果    |
> | u,v | Barycentric coordinates | 重心坐标       |
> | t   | Travel/Time             | 射线行进距离     |
> 


> [!NOTE]
> 最终结果
>
> $$
> \begin{aligned}
> &\det=\mathbf{P}\cdot \mathbf{E_{1}},\;u=\frac{\mathbf{P}\cdot \mathbf{T}}{\det},\;v=\frac{\mathbf{Q}\cdot \mathbf{D}}{\det},\;t=\frac{\mathbf{Q}\cdot \mathbf{E_{2}}}{\det} \\
> &\begin{cases}
> 	0\leq u,v\leq 1 \\
> 	t>0
> \end{cases}
> \end{aligned}
> $$

- 为什么最后要 设变量替换叉乘？
	1. 计算的时候重复使用
	2. 存变量可以提前算det，如果det≈0，那就直接return

> [!NOTE]
> 代码实现
>
> 
> ```cpp
> #include <cmath>
> 
> struct Vec3 {
>     float x, y, z;
> };
> 
> // 基础向量运算
> inline Vec3 operator-(const Vec3& a, const Vec3& b) {
>     return { a.x - b.x, a.y - b.y, a.z - b.z };
> }
> inline float dot(const Vec3& a, const Vec3& b) {
>     return a.x * b.x + a.y * b.y + a.z * b.z;
> }
> inline Vec3 cross(const Vec3& a, const Vec3& b) {
>     return {
>         a.y * b.z - a.z * b.y,
>         a.z * b.x - a.x * b.z,
>         a.x * b.y - a.y * b.x
>     };
> }
> 
> constexpr float EPSILON = 1e-8f;
> 
> // 光线与三角形求交
> // orig/dir: 光线起点 O 和方向 D
> // v0/v1/v2: 三角形三个顶点
> // 命中时返回 true，并写出 t（沿光线的距离）、u、v（重心坐标）
> bool rayTriangleIntersect(
>     const Vec3& orig, const Vec3& dir,
>     const Vec3& v0, const Vec3& v1, const Vec3& v2,
>     float& t, float& u, float& v)
> {
>     Vec3 E1 = v1 - v0;          // E1 = V1 - V0
>     Vec3 E2 = v2 - v0;          // E2 = V2 - V0
> 
>     // P = D × E2  —— 第一个被复用的叉乘
>     Vec3 P = cross(dir, E2);
> 
>     // det = P · E1  —— 行列式 / 平行六面体有符号体积
>     float det = dot(P, E1);
> 
>     // det 接近 0 → 光线与三角形平行，提前退出
>     // （若要做背面剔除，可改成 if (det < EPSILON) return false;）
>     if (std::fabs(det) < EPSILON) return false;
> 
>     float invDet = 1.0f / det;
> 
>     Vec3 T = orig - v0;         // T = O - V0
> 
>     // u = (P · T) / det，复用了上面的 P
>     u = dot(P, T) * invDet;
>     if (u < 0.0f || u > 1.0f) return false;  // 重心坐标越界，提前退出
> 
>     // Q = T × E1  —— 第二个被复用的叉乘
>     Vec3 Q = cross(T, E1);
> 
>     // v = (Q · D) / det，复用 Q
>     v = dot(Q, dir) * invDet;
>     if (v < 0.0f || u + v > 1.0f) return false;
> 
>     // t = (Q · E2) / det，再次复用 Q
>     t = dot(Q, E2) * invDet;
> 
>     return t > EPSILON;   // 命中点在光线前方
> }
> ```
